# Kurban AI — Özel ikon seti

28 özel çizim. Ana renk #07563A, açık yeşil #DFEAD2, orta yeşil #A8C59A, altın #E4CDA3. 64×64 SVG viewBox; PNG 256 ve 512 px, alfa kanallı şeffaf zemin. SVG-outline klasörü beş navigasyon ikonunun tek renk versiyonlarını içerir. Önizlemedeki açık renk kutular ikon dosyalarına dahil değildir.

## Expo

PNG: `import { Image } from 'react-native';` ve `<Image source={require('./icons/png-256/cattle.png')} style={{width:48,height:48}} resizeMode="contain" />`.

SVG: `npx expo install react-native-svg` ve SVG dosyası import edilecekse `react-native-svg-transformer` Metro yapılandırması gereklidir. Alternatif olarak SVG içeriğini `SvgXml` ile göster. Navigasyon 24–28 dp, işlem ikonları 28–36 dp, kategori ikonları 48–64 dp önerilir.
